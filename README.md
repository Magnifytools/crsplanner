# CRS Planner

Static site: CRS calculator, CLB converter and Express Entry draws history.

- `data/rules/*.json`: rules with source URL, source modification date and last check date.
- `data/draws.json`: generated by `node scripts/draws.mjs --fetch` (GitHub Action every 3 hours; dated raw copies in `data/archive/`).
- `data/ptimes.json`: IRCC processing times, generated by `node scripts/ptimes.mjs --fetch` from the JSON files behind IRCC's processing times tool (same GitHub Action as the draws).
- `npm test`: CRS engine tests (profiles verified against IRCC's calculator on 2026-10-14: A 469, B 402, C 428).
- `npm run build`: writes `dist/`. Cloudflare Pages: build command `npm run build`, output `dist`.
